# NewWave 점수표

이 포크가 무엇을 위해 존재하는지(여러 CLI 에이전트 세션을 한 창에서 굴리는 관제 터미널)를 기준으로
항목을 나누고 100점 만점으로 채점한다. 목표 점수를 지시받으면 이 표를 기준으로 회차를 돌리고,
회차마다 무엇을 올렸는지 아래 이력에 기록한다.

- 채점 기준일: 2026-09-06 / 기준 버전: v0.14.59
- 점수는 "구현됐다"가 아니라 **실사용에서 그 항목이 제 역할을 하는가**로 매긴다.
- 검증되지 않은 기능은 만점을 주지 않는다(코드가 있어도 실사용 확인 전이면 감점 유지).

## 감점 사유 요약(=다음에 올릴 여지)

1. 실사용 검증이 안 끝난 기능이 여럿(호버 미리보기, 학습·자동완성, 팔레트) — 확인되면 각 항목 +1~2
2. 완료 감지가 벨에 의존 — 스크롤백에서 프롬프트 복귀를 직접 읽으면 +3 수준
3. 사이드바 UI 테스트 부재 — 렌더 테스트 도입 시 품질 +3
4. 폴더 자동 분류(cwd 기반), 색 자동 배정, 스니펫 확장 등 미구현 기능
