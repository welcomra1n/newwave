# NewWave 점수표

이 포크의 목적(여러 CLI 에이전트 세션을 한 창에서 굴리는 관제 터미널)을 기준으로 파트를 나눈다.
**총합이 100점이 아니라 파트마다 각각 100점 만점**이다.

- 기준일 2026-09-06 / 기준 버전 v0.14.59
- 점수는 "코드가 있다"가 아니라 **실사용에서 그 파트가 제 역할을 하는가**로 매긴다.
- 실사용 확인이 안 된 기능은 만점을 주지 않는다.
- 목표 점수를 지시받으면 해당 파트를 그 점수까지 회차 반복하고, 회차마다 아래 이력에 기록한다.

## 파트별 점수 (각 100점 만점)

### 1. 세션 목록·탐색 — 78
있음: 목록·제목/내용 검색·에이전트 필터·상태 필터·정렬 3종(최근/이름/상태)·폴더 그룹·드래그 배정·핀·한 줄 컴팩트 행·호버 미리보기·서브에이전트 자동 제외.
감점: 폴더 자동 분류 없음(-8) / 500개 상한 뒤 페이징 없음(-5) / 호버 미리보기 실사용 미검증(-5) / 목록 새로고침이 수동·이벤트성이고 파일 감시가 아님(-4).

### 2. 세션 복귀 동선 — 80
있음: Ctrl+Shift+J 점프 팔레트(대기 우선·검색·↑↓/Enter·에이전트 아이콘), 클릭 재개, 닫힌 세션은 `--resume`으로 재오픈, 작업표시줄 깜빡임·대기 수 배지.
감점: 앱 밖에서 부를 전역 단축키 없음(-10) / 팔레트가 사용 빈도·최근 순을 학습하지 않음(-6) / 실사용 미검증(-4).

### 3. 완료 감지·알림 — 65
있음: 터미널 벨을 유일 근거로 삼아 오탐 차단, 삐 소리, 세션 색 오버레이 + 경과 시간 카운터, OS 알림(옵션·현재 꺼둠).
감점: 벨을 안 울리는 에이전트는 45초 정적 폴백뿐(-15) / 작업중·대기 상태가 출력 유무 추정이라 도구 장시간 실행과 구분이 약함(-12) / 여러 개 동시 완료 시 묶음 표시 없음(-8).

### 4. 세션 정리(삭제·보관) — 85
있음: 다중 선택 삭제(한 번 클릭), 블록 헤더 우클릭 삭제, 휴지통 이동, 실행 중이면 에이전트 종료 후 삭제, 재생성 파일 자동 제거, 삭제 표시 영속, 회귀 테스트.
감점: 휴지통 복구 UI 없음(-10) / 대량 삭제 시 되돌리기 없음(-5).

### 5. 터미널 가독성 — 70
있음: 내 메시지 하이라이트(색·배경·on/off 설정), DOM 렌더러로 분할 시 선명도 확보, D2Coding + CJK 폴백, 세션 색이 테두리까지.
감점: 에이전트 출력 구조화(도구 호출 접기, 요약 접기) 없음(-15) / 스크롤백 검색은 업스트림 그대로(-8) / 하이라이트가 `> ` 마커 의존이라 마커가 바뀌면 무력(-7).

### 6. 링크·복사 동선 — 85
있음: 두 줄로 쪼개진 URL 결합(단위·프로바이더 테스트 10건), 지정 브라우저(`web:externalbrowser`)로 열기, 중복 실행·따옴표 오염 차단.
감점: 파일 경로 클릭 열기 없음(-10) / 세 줄 이상 분할 URL 미대응(-5).

### 7. 입력 보조 — 80
있음: 빠른 답변 버튼(설정 편집), Alt+1~5 전송, 자주 쓴 문장 학습(3회 이상·노이즈 제외·우클릭 삭제), → 자동완성, 학습 테스트 5건.
감점: 스니펫 확장(`;;키워드`) 없음(-8) / 폴더별 버튼 세트 없음(-7) / 실사용 미검증(-5).

### 8. 시각적 식별(색·상태) — 86
있음: 세션 색이 제목·블록 테두리·완료 오버레이까지 일관, 포토샵식 피커(SV판·색조 레일·스포이드·hex·스와치), 상태 캡슐(열림/작업/대기/실행중) + 좁은 폭 자동 축약.
감점: 폴더·프로젝트별 색 자동 배정 없음(-9) / 색맹 대비 패턴 구분 없음(-5).

### 9. 안정성·품질 — 58
있음: Go 4건 + 프론트 61건 테스트(삭제 재생성·코덱스 서브에이전트·링크 결합·학습), 타입체크·번들 빌드 절차.
감점: 사이드바·팔레트 등 UI 컴포넌트 테스트 전무(-20) / 번들 빌드를 건너뛰어 릴리즈 1건 깨진 전례(v0.14.53)(-10) / 업스트림 유래 타입 에러 8건 상주(-7) / 프론트 테스트가 부하 시 타임아웃으로 산발적 실패(-5).

### 10. 배포·업데이트 — 84
있음: 커밋 푸시 → CI 빌드 → 자동 업데이트 수신, 캐시·타깃 정리로 19분 → 12분, 이전 실행 자동 취소.
감점: 맥 잡 선택 실행이 토큰 스코프 문제로 미적용(-8) / 릴리즈 노트 자동 생성 없음(-5) / 빌드 12분은 여전히 김(-3).
